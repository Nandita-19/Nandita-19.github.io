SQL Job Market Analysis

Exploring Data Analyst compensation and skill demand through a public set of PostgreSQL queries.

PostgreSQLSQL joinsCTEsAggregations

Why this work matters

Job-market datasets contain useful signals about compensation and technical skills, but the most informative comparisons require combining job postings, employers, and skills tables. This independent analysis uses SQL to ask focused career-market questions.

Questions investigated

  • What are the highest-paying Data Analyst jobs in the dataset?
  • Which skills accompany the highest-paying postings?
  • Which skills occur most frequently in Data Analyst postings?
  • Which skills correlate with higher average posted salaries?
  • Which skills offer a potentially attractive demand-versus-pay trade-off?
